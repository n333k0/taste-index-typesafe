# Taste Index — after typesafe.ai

A brand guide an AI agent can follow, so every new feature looks like it came from the same designer. Measured from typesafe.ai's computed styles, tagged M (measured) / V (seen) / I (inferred) / X (extension), and extended with motion presets, an effects library and 45 website modules shown on desktop and phone.

- **Live:** https://n333k0.github.io/taste-index-typesafe/
- **Agents start here:** [DESIGN.md](DESIGN.md), then `brand.css` + `brand.js`
- **One module, full size:** `m.html?id=pricing&scheme=signal&motion=snappy`
- **Make the next index (Shipped template):** [TEMPLATE.md](TEMPLATE.md) · tokens for Framer: [tokens.json](tokens.json)
- **History:** [CHANGELOG.md](CHANGELOG.md), snapshots in `versions/`

Credits: typesafe.ai (measured system), weareactsofimagination.com (index menu and other AOI-inspired ideas, redrawn), HyperFrames animation rules (FX names and timing), Hairline by Lucas Marques (MIT, line figures), Shipped's mobile-menu component.
