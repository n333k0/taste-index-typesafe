01 / Principles

seven rules the site already follows

01 · two voices

A soft grotesk talks to people; a pixel terminal font talks like a machine. Every label picks one.

02 · square everything

Radius is 0. Tiles, windows, buttons, images. Only code (6px) and tables (8px) soften.

03 · one page, one colour

Each page owns a single background: paper, pink, sage, ink. Contrast comes from ink blocks.

04 · magenta means "you"

#d45bb6 appears only where the pointer is: hover, active chip, current tile.

05 · huge and tight

Headlines run at 150px with 0.8 line-height and touch. Body stays 17px everywhere.

06 · the UI is a toy computer

Windows with title bars, version numbers, clocks, Game of Life, base64. Software as decoration.

07 · motion computes

Things tick, blink and loop linearly. Hovers swap instantly. Nothing floats in.

08 / Do + Don’t

the short version

Do
  • Pick one page colour per page; build contrast with ink blocks.
  • Put labels in pixel or mono, everything people read in the grotesk.
  • Write headings in sentence case and let text-transform: capitalize do Title Case.
  • Use magenta only for the thing under the pointer.
  • Wrap demos, data and widgets in a window with a version-numbered title bar.
  • Mark section corners with 10px crop marks.
  • Back every claim with a number and a link to proof.
Don’t
  • Round corners, add drop shadows or use gradient buttons.
  • Fade or slide content in on scroll; it should already be there.
  • Ease hover backgrounds. Tiles swap in 0s.
  • Mix two page colours in one viewport, outside a framed panel.
  • Set body copy in the pixel font, or headlines in mono.
  • Shrink body text on phones. It is 17px everywhere.
  • Put emoji in headings or buttons.
